# Blackjack

A simple Blackjack game built with HTML, CSS, and JavaScript.

This was my first JavaScript project and was built while learning the fundamentals of JavaScript and DOM manipulation.

## Features

- Random card generation
- Player and dealer hands
- Pull another card or stop
- Win, lose, and draw outcomes
- Balance system
- Balance saved using LocalStorage
- Add balance through a simple top-up page
- Dynamic card rendering
- Basic responsive UI

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How It Works

The game starts with a balance and deals cards to the player and dealer.

The player can pull additional cards or stop their turn. The final result is determined by comparing the player's total with the dealer's total.

The balance is updated after each round and stored in LocalStorage so it remains after refreshing the page.
